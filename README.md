# AviUtlExportSlides — 配布終了

PNGを画像としてPowerPointへ貼り付ける補助ツールです。編集可能PPTXを生成する [AviUtlIntervalPngExport / EditablePptxExport](https://github.com/GGAkyo/AviUtlIntervalPngExport/tree/main/EditablePptxExport) があるため、独立した案内・配布を終了しました。

今後は [編集可能PPTX版](https://github.com/GGAkyo/AviUtlIntervalPngExport/releases/latest/download/EditablePptxExport.zip) を利用してください。対応はAviUtl 1.xです。

リポジトリはアーカイブします。旧版Releaseは履歴として残しますが、今後の利用には上記の編集可能PPTX版を推奨します。
